# Smart AI File Organizer 🤖
Sistem automasi yang berjalan di latar belakang (System Tray) untuk menyortir file secara cerdas menggunakan Python, Watchdog, NLP (PyMuPDF), dan OCR (Tesseract).

## Cara Menjalankan
1. Instal semua requirements: `pip install -r requirements.txt`
2. Pastikan mesin Tesseract OCR sudah terinstal dan diletakkan di dalam folder `Tesseract-OCR`.
3. Jalankan `python main.py`
